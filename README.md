# 🎬 EditOnGo Studio

EditOnGo Studio is a free browser-based video editing application currently in development.

here is the link [https://chrislegend95.github.io/EditOnGo/]

The goal of EditOnGo Studio is to provide a powerful video editing experience directly in the browser without requiring users to install traditional editing software.

## ✨ Features

### ⚠️ Saving project not working at the moment.
  The project is still in start of it's stage and saving project will work but the audio wont be saved when importing a saved project file.
  Keep in mind that the edit is not saving anything you have done so if you make a video you must exsport or you will have lost the project.

### 🎞️ Video Editing
- Multi-track video and audio timeline
- Timeline ruler and playhead
- Split / razor tool
- Clip selection and deletion
- Magnetic snapping
- Grouping clips
- Undo and redo
- Adjustable timeline zoom
- Adjustable track height

### 🖥️ Video Preview
- Canvas-based video preview
- Play and pause controls
- Frame stepping
- Jump to start and end
- Loop playback
- In and Out points
- Fullscreen preview
- Composition grid
- Canvas snapping
- On-screen transform controls

### 🔄 Transform Tools
- Move clips directly in the preview
- Resize clips using transform handles
- Rotation support
- Transform gizmo
- Position, scale, and rotation controls
- Keyframe animation support

### 🎵 Audio
- Audio mixer
- Master volume control
- Live VU meter
- Multiple audio tracks
- Per-clip audio effects

### 📁 Media Library
- Import video files
- Import audio files
- Import images
- Drag and drop media
- Text overlays
- Background media
- Sample media generation

Supported media types include:

- MP4
- WebM
- MOV
- MP3
- WAV
- PNG
- JPG

### 💾 Projects
- Save projects
- Import previously saved projects
- Project settings
- Resolution settings
- Frame rate settings
- Aspect ratio settings

### 📤 Export
- Export video compositions
- Custom output file names
- Export settings
- Frame rate selection

## 🛠️ Technology

EditOnGo Studio is built using web technologies including:

- HTML
- CSS
- JavaScript
- HTML Canvas
- Web Audio APIs

The application runs directly in a modern web browser.

## 🚧 Development Status

EditOnGo Studio is currently under development.

Features, functionality, design, and performance may change as development continues.

## 🎯 Goal

The goal of EditOnGo Studio is to create a capable and accessible video editor that runs directly in the browser and provides useful editing tools without unnecessary barriers.
